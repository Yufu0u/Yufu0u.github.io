# Yufu0u 的个人学习网站

个人学习日志，托管在 GitHub Pages 上。

- 在线地址：https://yufu0u.github.io
- 技术：HTML / CSS 手写，评论用 giscus

## 文件结构

- `index.html` 首页
- `blog.html` 学习日志
- `about.html` 关于我
- `404.html` 访问错误页
- `favicon.svg` 站点图标（浏览器标签页上的小图标）
- `style.css` 全站样式

## 日常更新（每周日写日志）

1. 打开 `blog.html`，把新的一篇放在**最上面**（最新的在最前）。
2. 复制文件里「文章模板」那一段注释，填上日期、周数和正文。
3. 提交并推送：

```bash
git add .
git commit -m "blog: 第N周学习日志"
git push
```

## 改配色

`style.css` 最上面的 `:root` 里是一组颜色变量，改那几行就能换全站配色，
不用去翻每一个样式。常用的是：

- `--bg` 页面背景
- `--card` 卡片背景
- `--text` 正文颜色
- `--accent` 主题色（链接、按钮、高亮）
